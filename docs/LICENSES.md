# Code, dependencies, and mods

No license for the original Loadout ModSync code has been selected for this archive. Third-party notices are recorded in [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md); they do not license the whole project.

This repository does not contain game binaries or Workshop mods. Before serving someone else's mods, check each author's distribution terms. The API's distribution switch is off by default. Keep real server configurations, credentials, and saves out of Git.

When distributing a compiled build, include dependency notices and licenses. The pinned dependency lists are in the project root.
